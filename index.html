Hiding the URL and title from your PDF
Browsers automatically add the page URL and title at the top when printing. To remove them, turn off “Headers and footers” in the print dialog:
  • Desktop (Chrome, Edge, Firefox): More settings → uncheck “Headers and footers” Remembered — you only need to do this once.
  • Desktop (Safari): Uncheck “Print headers and footers” Remembered — you only need to do this once.
  • Mobile (Chrome, Android): Expand settings → uncheck “Headers and footers” May reset — check each time.
  • Mobile (Safari, iOS): Tap “Options” → turn off “Header and Footer” Resets each time — you’ll need to turn it off again before each print.
